# M12D.8.x — Playwright Full-System Regression Harness

## Goal

Provide a repeatable browser-level regression gate for the IpeNovel Preview environment.
The harness is intentionally separate from Vitest unit/integration coverage and does not replace database contract tests.

## Safety contract

- Default target: `https://r2-preview.ipenovel.com`.
- Allowed targets are Preview, `localhost`, and `127.0.0.1` only.
- Production hosts are rejected by configuration before tests start.
- Public smoke tests are read-only.
- Authenticated smoke tests are read-only.
- Mutation tests require explicit `E2E_ALLOW_MUTATION=1`.
- The package-cart mutation test removes any existing selection first and removes its test selection in `finally`.
- Checkout, wallet payment, slip upload, admin mutation, and production publishing are not automated by this milestone.

## Test layers

1. `public` — `/readyz`, public routes, published package visibility, same-origin 5xx/page errors.
2. `auth` — authenticated cart/account/library route smoke using Playwright storage state.
3. `mutation` — paid-package Add-to-Cart regression through the real UI and real `cart.add` tRPC request.

The mutation layer specifically guards the runtime failure fixed in M12D.8: a missing entitlement table causing `cart.add` to return HTTP 500.

## Authentication

No OAuth username, password, token, or browser profile is committed to the repository.
Capture a dedicated Preview test-account session once:

```powershell
npx pnpm@10.4.1 test:e2e:auth:capture
```

Complete OAuth in the opened browser, return to the terminal, and press Enter.
The resulting state is stored at `.playwright/.auth/user.json` and is ignored by Git.
Use `E2E_STORAGE_STATE` to choose a different path.

## Commands

Install the managed browser:

```powershell
npx pnpm@10.4.1 test:e2e:install
```

Run public smoke:

```powershell
npx pnpm@10.4.1 test:e2e:public
```

Run authenticated smoke:

```powershell
npx pnpm@10.4.1 test:e2e:auth
```

Run the reversible package-cart mutation regression on Preview:

```powershell
$env:E2E_ALLOW_MUTATION="1"
$env:E2E_NOVEL_IDENTIFIER="4050013"
$env:E2E_PACKAGE_LABEL="036 - 085"
npx pnpm@10.4.1 test:e2e:mutation
```

Run every configured project:

```powershell
npx pnpm@10.4.1 test:e2e
```

Without auth state, authenticated projects skip with an explicit reason.
Without `E2E_ALLOW_MUTATION=1`, the mutation project skips rather than changing Preview state.

## Artifacts

- Failure screenshots: `test-results/playwright/`
- Retained traces on failure: `test-results/playwright/`
- Retained videos on failure: `test-results/playwright/`
- HTML report: `playwright-report/`

All of these paths are ignored by Git.

## CI promotion rule

Public smoke can run on every Preview deployment with no secrets.
Authenticated and mutation jobs should use an isolated Preview test account and inject its storage state as a CI secret/artifact.
Do not copy a personal browser profile or personal OAuth credentials into CI.
Promotion should require public smoke plus the package-cart regression when an authenticated test account is available.

## Admin / Workspace state

Admin smoke uses a separate state file: `.playwright/.auth/admin.json`.
Capture it by pointing the generic auth-capture helper at that path while signing in with a dedicated Preview admin account:

```powershell
$env:E2E_STORAGE_STATE=".playwright/.auth/admin.json"
npx pnpm@10.4.1 test:e2e:auth:capture
Remove-Item Env:E2E_STORAGE_STATE
npx pnpm@10.4.1 test:e2e:admin
```

The admin project is read-only and covers the critical admin/workspace route matrix.
If the saved account is not an admin, the project is expected to fail rather than bypass authorization.
